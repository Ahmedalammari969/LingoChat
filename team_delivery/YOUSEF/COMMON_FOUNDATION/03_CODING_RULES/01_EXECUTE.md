# توجيه التنفيذ: معايير وقواعد كتابة الكود النظيف

## المرحلة: 03_CODING_RULES
## العضو: يوسف خيري (YOUSEF)
## الدور: Backend / Database / Auth / REST Engineer

### الهدف:
دراسة واستيعاب معايير وقواعد كتابة الكود النظيف الخاص بمشروع LinguaChat وتطبيقه على نطاق مسؤوليتك (قاعدة البيانات PostgreSQL، هجرات Alembic، نماذج SQLAlchemy، مصادقة JWT و Bcrypt، مسارات REST).

### القواعد الإلزامية:
1. اقرأ العقود والوثائق في docs/ و _TEAM/00_SHARED/ أولاً.
2. لا تعدل أي ملفات تقع خارج نطاق ملكيتك: backend/app/database/**, backend/app/auth/**, backend/app/users/**, backend/app/rooms/**, backend/app/messages/**, backend/app/dashboard/**, backend/tests/unit/**, team_delivery/YOUSEF/**.
3. يمنع منعاً باتاً تعديل الملفات المحظورة: frontend/**, backend/app/websocket/**, backend/app/translation/**.
4. التزم بالأمان التام وخلو الكود من الأسرار.
5. التزم بقاعدة عدم استخدام 'none' في الترجمة، والالتزام بالأنواع الستة للـ WebSocket.
