# برومبت التنفيذ: بناء خدمة حفظ واسترجاع تاريخ الرسائل المترجمة (01_IMPLEMENT_IDE)

```text
أنت تعمل كمطور برمجيات محترف داخل مشروع: LinguaChat.
أنت تنفذ المهمة: TASK-10-MESSAGE-PERSISTENCE-AND-HISTORY-API (بناء خدمة حفظ واسترجاع تاريخ الرسائل المترجمة).

قبل أي خطوة:
1. اقرأ ملف TASK.md في هذا المجلد بدقة.
2. اقرأ العقود المرتبطة في _TEAM/00_SHARED/.
3. افحص الملفات الموجودة في المستودع قبل أي تعديل.

التعليمات الصارمة:
- التزم حصرياً بالملفات المسموح بتعديلها:
  * backend/app/messages/schemas.py
  * backend/app/messages/service.py
  * backend/app/rooms/router.py
- يمنع منعاً باتاً تعديل الملفات المحظورة:
  * frontend/**
  * backend/app/websocket/**
  * backend/app/translation/**
  * _TEAM/**
- لا تنشئ مشروعاً جديداً ولا تغير المعمارية.
- التزم بالأمان وخلو الكود من أي أسرار أو كلمات مرور.
- إذا وجدت أي تعارض أو غموض، توقف فوراً ولا تخترع حلاً وأبلغ قائد الفريق أحمد.

المطلوب تنفيذه بدقة:
- دوال create_message و save_translation في messages/service.py.
- مسار GET /rooms/{id}/messages مع التحقق من عضوية المستخدم (403 FORBIDDEN) والغرفة (404).
- إرجاع الرسائل السابقة مع دمج النص المترجم للغة المستخدم.

بعد التنفيذ، أنتج تقرير IMPLEMENTATION REPORT يوضح:
- ماذا تم تنفيذه

- نتائج الفحص
- ملاحظات التكامل
```
