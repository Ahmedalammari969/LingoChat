## وصف المهمة
تطوير وتجهيز عميل الـ API المركزي في frontend/src/api/client.js لدعم استدعاءات HTTP وحقن رمز التوكن تلقائياً ومعالجة الأخطاء المعيارية.

## لماذا هذه المهمة مهمة للنظام
توحيد طلبات الـ HTTP وضمان الحقن الآمن لـ JWT ومعالجة الأخطاء 401 مركزياً.

## المتطلبات الوظيفية
- ضبط Base URL: http://localhost:8000/api/v1.
- حقن ترويسة Authorization: Bearer <token> تلقائياً من localStorage.
- معالجة أخطاء 401 وحذف التوكن المنتهي.
- استخراج كائنات الأخطاء القياسية error.code و error.message.

## المتطلبات غير الوظيفية
- الأمان التام وعدم طباعة التوكن في console.log.

## Edge Cases / الحالات الحدية
- انقطاع الاتصال بالشبكة.
- استلام استجابات غير متوقعة أو كود 500.
