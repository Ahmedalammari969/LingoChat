1. ما هو مشروع LinguaChat وما هي مهمتك بالضبط؟

مشروع LinguaChat هو تطبيق محادثة جماعية فورية متعدد اللغات. فكرته ببساطة: مستخدم عربي ومستخدم إنجليزي ومستخدم فرنسي في نفس الغرفة؛ العربي يكتب بالعربية، الإنجليزي تصله الرسالة مترجمة للإنجليزية في نفس الثانية، والفرنسي تصله بالفرنسية، مع إمكانية رؤية النص الأصلي أيضاً.

مهمتك يا أحمد (قائد المشروع ومهندس الواجهات والتكامل):
أنت مسؤول عن وجه المشروع بالكامل (الـ Frontend) باستخدام React + Vite، بالإضافة إلى إدارة وتنسيق تكامل باقي أعضاء الفريق وإصدار النسخة النهائية. أنت تبني شاشات الدخول، استعراض الغرف، واجهة الدردشة اللحظية، لوحة التحكم، وعميل استدعاء الـ API والـ WebSocket في المتصفح.

3. حدود الملكية: ما الذي تعدله وما الممنوع لمسه قطيعاً؟

✅ الملفات والمجلدات التي تملكها وتعدلها أنت فقط:
  • frontend/src/** (كافة ملفات الواجهة: الصفحات، المكونات، الخطافات، التنسيقات).
  • frontend/index.html, frontend/package.json, frontend/vite.config.js.
  • team_delivery/AHMED/** (مجلد عملك ومهامك وتقارير تسليمك).
⛔ الملفات الممنوع عليك تعديلها نهائياً (Forbidden):
يمنع منعاً باتاً تعديل أي ملف داخل backend/** أو docs/**. أنت تتعامل مع الـ Backend كخدمة جاهزة وفق العقود الرسمية.

5. كيف تطبق خطوة بخطوة عملياً كأنك لا تعرف شيئاً؟ (Step-by-Step Walkthrough)

1
افتح مجلد مهامك:
في بيئة التطوير (VS Code أو Antigravity)، افتح المجلد: team_delivery/AHMED/tasks/. ستجد 11 مجلداً مرتبة من TASK-01 إلى TASK-11.
2
ابدأ بالمهمة الأولى (مثلاً TASK-02):
ادخل مجلد TASK-02-FRONTEND-FOUNDATION/، واقرأ ملف TASK.md لتعرف ماذا يطلب منك بالضبط.
3
تنفيذ الكود (IMPLEMENT):
افتح ملف 01_IMPLEMENT_IDE.md، وانسخ نصه بالكامل، وضعه للذكاء الاصطناعي (AI Assistant). سيقوم بكتابة وتعديل الكود المطلوب داخل frontend/src/index.css دون لمس ملفات أخرى.
4
تشغيل الاختبار والتحقق (TEST):
افتح ملف 02_TEST_IDE.md، وشغل الأمر المكتوب فيه داخل الطرفية (Terminal):
cd frontend && npm run build
تأكد أن البناء ينجح بدون أي خطأ (0 errors).
5
المراجعة السحابية (CLOUD REVIEW):
انسخ نص ملف 03_EXTERNAL_AI_REVIEW.md مع الكود المكتوب إلى مراجع ذكاء اصطناعي مستقل (ChatGPT أو Claude أو Gemini) وتأكد من حصولك على تقييم PASS.
6
التسليم والانتقال للمهمة التالية (HANDOFF):
أنشئ تقرير إنجاز سريع داخل مجلد handoff/ ثم انتقل للمهمة التالية مباشرة بنفس الطريقة!
