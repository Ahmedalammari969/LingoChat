حالة الدليل: إرشادات تطبيقية مباشرة (Step-by-Step Practical)

1. ما هو مشروع LinguaChat وما هي مهمتك بالضبط؟

مشروع LinguaChat يقوم على ترجمة الرسائل في الوقت الحقيقي؛ إذا أرسل أحدهم رسالة بالعربية وأنت تفضل الإنجليزية، تترجم لك فوراً دون تأخير.

مهمتك يا مؤيد (مهندس خدمات ومحركات الترجمة والكاش):
أنت عقل الترجمة والذكاء الاصطناعي في المشروع! مسؤوليتك هي بناء وحدة الترجمة المتكاملة داخل backend/app/translation/. مهمتك تشمل: كشف لغة الرسالة تلقائياً (Language Detection)، استدعاء محرك LibreTranslate عبر HTTP بمهلة 10 ثوانٍ، تفعيل مزود Google الاحتياطي، تخزين الترجمات في كاش سريع (In-Memory و Redis)، والأهم من ذلك تطبيق قاعدة الـ Identity الذكية لتوفير الموارد عندما تكون لغة المرسل هي نفس لغة المستقبل.

2. موقعك في المعمارية الهندسية للنظام (Architecture Position)

+-----------------------------------------------------------------------------------+ | WebSocket Server (Mohammed) يستدعي خدمتك عبر: | | translate_message(text="مرحباً", source_language="ar", target_language="en") | +------------------------------------------+----------------------------------------+ | استدعاء مباشر في الذاكرة v +-----------------------------------------------------------------------------------+ | [نطاقك الحصري - MOAYAD] | | Translation Engine Architecture | | | | 1. فحص تطابق اللغات (Identity Rule): | | إذا source == target -> أرجع النص الأصلي فوراً مع source_used="identity" | | | | 2. فحص الكاش (Cache Lookup): | | فحص مفتاح SHA-256 في الذاكرة / Redis -> عند المطابقة أرجع source_used="cache" | | | | 3. مزود LibreTranslate (Primary Provider): | | استدعاء HTTP بمهلة 10 ثوانٍ -> عند النجاح أرجع source_used="libretranslate" | | | | 4. مزود Google Fallback (Secondary Provider): | | عند تعطل المزود الأساسي -> أرجع source_used="google" | +-----------------------------------------------------------------------------------+
⚠️ قاعدة الـ Identity الصارمة وتأكيد حظر "none":
- إذا كانت source_language == target_language، يجب أن تعيد: source_used = "identity" و confidence = 1.0.
- ممنوع منعاً باتاً استخدام القيمة "none" في أي حقل أو استجابة في النظام.

3. حدود الملكية: ما الذي تعدله وما الممنوع لمسه قطيعاً؟

✅ الملفات والمجلدات التي تملكها وتعدلها أنت فقط:
  • backend/app/translation/** (detector, providers, cache, service).
  • backend/tests/unit/test_translation* (اختبارات الترجمة والكاش).
  • team_delivery/MOAYAD/** (مجلد عملك ومهامك وتقارير تسليمك).
⛔ الملفات الممنوع عليك تعديلها نهائياً (Forbidden):
يمنع تعديل ملفات frontend/** أو backend/app/websocket/** أو backend/app/database/** أو docs/**.

4. خريطة طريق مهامك الـ 9 من البداية حتى النهاية (Your 9 Tasks)

رقم المهمة اسم المهمة الملف الأساسي للتعديل الهدف والمطلوب باختصار
TASK-01 TRANSLATION-ANALYSIS قراءة فقط دراسة عقد docs/translation-contract.md وقاعدة Identity.
TASK-02 LANGUAGE-DETECTION backend/app/translation/detector.py بناء كاشف اللغات وإرجاع رموز ISO 639-1 دون رفع استثناءات.
TASK-03 LIBRETRANSLATE-PROVIDER backend/app/translation/providers.py بناء عميل LibreTranslate غير المتزامن مع مهلة زمنية 10 ثوانٍ.
TASK-04 GOOGLE-FALLBACK backend/app/translation/providers.py بناء المزود الاحتياطي عند تعطل المزود الأساسي.
TASK-05 TRANSLATION-CACHE backend/app/translation/cache.py بناء طبقة الكاش السريعة بمفتاح SHA-256 وصلاحية 3600 ثانية.
TASK-06 IDENTITY-TRANSLATION backend/app/translation/service.py تطبيق قاعدة الـ Identity ومنع استخدام القيمة "none" نهائياً.
TASK-07 ERROR-HANDLING backend/app/translation/service.py معالجة الاستثناءات وتوليد TranslationError عند فشل كافة المزودين.
TASK-08 SERVICE-INTEGRATION backend/app/translation/service.py تجميع كافة الوحدات في الدالة الرئيسية translate_message.
TASK-09 TRANSLATION-FINAL-QA backend/app/translation/** الفحص الشامل وتشغيل كافة اختبارات الترجمة والكاش بنسبة 100%.

5. كيف تطبق خطوة بخطوة عملياً؟ (Step-by-Step Walkthrough)

1
افتح مجلد مهامك: team_delivery/MOAYAD/tasks/.
2
افتح المهمة الحالية: اقرأ TASK.md لتفهم المدخلات والمخرجات.
3
التنفيذ بالذكاء الاصطناعي: انسخ برومبت 01_IMPLEMENT_IDE.md إلى AI المساعد لتنفيذ الكود.
4
شغل الاختبارات: نفذ الأمر من 02_TEST_IDE.md:
pytest backend/tests/unit/test_translation* -v
5
المراجعة السحابية: راجع عبر 03_EXTERNAL_AI_REVIEW.md وتأكد من PASS، ثم انتقل للمهمة التالية.
