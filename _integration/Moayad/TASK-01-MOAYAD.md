# وحدة كشف اللغات التلقائي (Language Detection Module)

## 1. معلومات المهمة

- **رقم المهمة**: `TASK-01-MOAYAD`
- **العضو المسؤول**: مؤيد الصوفي
- **الدور**: مهندس الترجمة والذكاء الاصطناعي
- **الحالة**: جاهزة للتنفيذ (Ready to Start)
- **الأولوية**: عالية (High)

## 2. هدف المهمة

تنفيذ دالة كشف اللغة التلقائي `detect_language(text: str) -> str` في `backend/app/translation/detector.py` باستخدام مكتبة كشف اللغات (مثل `langdetect` أو خوارزمية مطابقة موثوقة)، بحيث تعيد رمز اللغة القياسي ISO 639-1 (مثل "ar", "en", "fr") أو تعيد `"unknown"` عند الفشل دون رفع أي استثناءات تؤدي لانهيار الخادم.

## 3. لماذا هذه المهمة؟

عندما يرسل المستخدم رسالة بدون تحديد لغة المصدر صراحة (أو يمرر `"auto"` عبر WebSocket)، يحتاج النظام إلى الكشف التلقائي الدقيق عن لغة النص المكتوب لتوجيهه للمترجم الصحيح.

## 8. المتطلبات الوظيفية

1. **تطبيق دالة `detect_language(text: str) -> str`**:
   - استقبال نص الإدخال `text` (تنظيف المسافات الفارغة).
   - الكشف عن لغة النص وإرجاع رمز ISO 639-1 المكون من حرفين (مثل: `"ar"`, `"en"`, `"es"`, `"fr"`, `"de"`, `"zh"`, `"ru"`).
   - في حال كان النص فارغاً، أو رموزاً غير مفهومة، أو فشل التحليل: يجب إرجاع `"unknown"` كقيمة نصية.
   - **قاعدة الأمان**: الدالة غير متزامنة `async def detect_language(text: str) -> str` وتلتقط كافة الاستثناءات داخلياً ولا ترفع استثناءً أبداً (Never raises an exception).

## 9. المتطلبات غير الوظيفية

- **الأداء والسرعة**: سرعة تنفيذ فائقة (أقل من 20ms) حتى لا تؤخر تدفق الرسائل الفورية في الـ WebSocket.
- **الاستقرار**: مقاومة الانهيار مع النصوص الغريبة، الرموز التعبيرية (Emojis)، والنصوص المختلطة.

## 10. Edge Cases (الحالات الطرفية)

- إدخال نص يحتوي على Emojis فقط (مثل: `😊🚀🔥`) -> إرجاع `"unknown"`.
- إدخال نص فارغ `""` أو مسافات فقط `"   "` -> إرجاع `"unknown"`.
- إدخال أرقام فقط `"123456789"` -> إرجاع `"unknown"`.
- إدخال نص عربي قصير (مثل: `"مرحبا"`) -> إرجاع `"ar"`.
- إدخال نص إنجليزي (مثل: `"Hello world"`) -> إرجاع `"en"`.

## 11. خطوات التنفيذ

- **الخطوة 1**: فحص ملف `backend/app/translation/detector.py`.
- **الخطوة 2**: استيراد وضبط مكتبة الكشف (`langdetect` أو آلية كشف آمنة).
- **الخطوة 3**: كتابة دالة `detect_language` مع كتلة `try...except Exception` تعيد `"unknown"` عند أي خطأ.
- **الخطوة 4**: كتابة اختبارات الوحدة في `backend/tests/unit/test_translation_detector.py`.
- **الخطوة 5**: تشغيل الاختبارات والتأكد من نجاحها بالكامل.
