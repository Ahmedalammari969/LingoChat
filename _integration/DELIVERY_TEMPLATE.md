## 8. التحقق من المعايير الأمنية (Security Checklist)

- [ ] عدم وجود أي أسرار، كلمات مرور، أو مفاتيح API داخل الكود المصدري (No Hardcoded Secrets).
- [ ] تشفير كلمات المرور باستخدام bcrypt (Cost >= 12) وعدم تخزينها كنص صريح.
- [ ] التحقق الصارم من صحة مدخلات الـ API والـ WebSocket عبر Pydantic schemas.
- [ ] التحقق من صلاحية رموز JWT وعدم تسجيل التوكن في السجلات (No JWT in logs).
- [ ] حماية قاعدة البيانات باستخدام ORM فقط ومنع الـ Raw SQL Injection.
- [ ] عدم إرجاع بيانات حساسة في استجابات الـ API (مثل `hashed_password`).
