## 1. ملخص المشروع والمنظومة (Project Overview)

مشروع **LinguaChat** هو تطبيق ويب متكامل للمحادثة الفورية متعددة اللغات يعتمد على معمارية العميل/الخادم الحديثة:
- **الواجهات الأمامية (Frontend)**: مبنية باستخدام React 18 و Vite ونظام تصميم عصري يدعم الثيم الداكن والتأثيرات الزجاجية واللغتين العربية والإنجليزية.
- **الخادم والخدمات الخلفية (Backend)**: مبني بواسطة FastAPI مع بنية معمارية قوية ومنظمة في طبقات.
- **قواعد البيانات (Database)**: نماذج SQLAlchemy متطورة مع PostgreSQL و Alembic.
- **الاتصال الفوري (Real-Time Gateway)**: اتصالات WebSocket حية تدعم نبضات الـ Heartbeat وإعادة الاتصال الذكي.
- **محركات الترجمة (Translation Engines)**: كشف اللغات والترجمة الفورية التلقائية باستخدام LibreTranslate ونظام التخزين المؤقت (Cache).

## 4. دليل التشغيل السريع للمشروع (Quick Start Guide)

### أ. تشغيل الواجهات الأمامية (Frontend):
```bash
cd frontend
npm install
npm run dev
# يفتح التطبيق على: http://localhost:5173
```

### ب. تشغيل الخادم الخلفي (Backend):
```bash
cd backend
python -m uvicorn app.main:app --reload --port 8000
# التوثيق التفاعلي للـ API على: http://localhost:8000/docs
```
