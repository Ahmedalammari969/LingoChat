## 2. هدف المهمة

تنفيذ خدمات ومسارات إدارة غرف المحادثة الرسمية:
1. `POST /api/v1/rooms` (إنشاء غرفة جديدة وإضافة منشئها كعضو تلقائياً).
2. `GET /api/v1/rooms` (استعراض قائمة الغرف المتاحة مع الترقيم Pagination وعدد الأعضاء).
3. `POST /api/v1/rooms/{room_id}/join` (انضمام المستخدم لغرفة محددة).
4. دوال التحقق من العضوية (`is_user_member_of_room`) لاستخدامها كخدمة مشتركة.

## 3. لماذا هذه المهمة؟

الغرف هي الحاوية الأساسية للمحادثات المتعددة الأطراف. يعتمد عليها الـ WebSocket للتحقق من السماح للمستخدم بالدخول إلى اتصال الغرفة، ويعتمد عليها الـ Frontend لعرض الغرف والانضمام إليها.

## 8. المتطلبات الوظيفية

1. **مسار `POST /api/v1/rooms`**:
   - حماية عبر Bearer JWT (المستخدم المسجل).
   - استقبال Body: `{"name": "string"}` (1-100 حرف).
   - إنشاء الغرفة وتعيين `created_by` بمعرف المستخدم الحالي.
   - إضافة المستخدم تلقائياً إلى جدول `room_members`.
   - توليد رابط الدعوة `invitation_link` بالصيغة: `/rooms/{id}/join` أو رابط التطبيق.
   - إرجاع استجابة `201 Created`:
     ```json
     {
       "id": "uuid",
       "name": "string",
       "invitation_link": "string",
       "created_by": "uuid",
       "created_at": "ISO8601"
     }
     ```
2. **مسار `GET /api/v1/rooms`**:
   - حماية عبر Bearer JWT.
   - معلمات اختيارية: `limit` (افتراضي 20، أقصى حد 100)، `offset` (افتراضي 0).
   - إرجاع قائمة الغرف مع عدد الأعضاء في كل غرفة `member_count` وإجمالي الغرف `total`.
   - استجابة `200 OK`:
     ```json
     {
       "rooms": [
         {
           "id": "uuid",
           "name": "string",
           "member_count": 0,
           "created_at": "ISO8601"
         }
       ],
       "total": 0,
       "limit": 20,
       "offset": 0
     }
     ```
3. **مسار `POST /api/v1/rooms/{room_id}/join`**:
   - حماية عبر Bearer JWT.
   - التحقق من وجود الغرفة (إذا لم توجد: إرجاع `404 Not Found` مع `ROOM_NOT_FOUND`).
   - التحقق مما إذا كان المستخدم عضواً بالفعل (إذا كان عضواً: إرجاع `409 Conflict` مع `ALREADY_IN_ROOM`).
   - إضافة المستخدم وإرجاع `200 OK`:
     ```json
     {
       "room_id": "uuid",
       "user_id": "uuid",
       "joined_at": "ISO8601"
     }
     ```
4. **دالة `is_user_member_of_room(db, room_id, user_id) -> bool`**:
   - دالة سريعة وغير متزامنة للاستخدام في التحقق الأمني الداخلي.

## 9. المتطلبات غير الوظيفية

- **الأداء**: استخدام استعلامات تجميعية كفؤة لحساب `member_count` دون مشكلة N+1 queries.
- **التكامل المعماري**: فصل استعلامات قاعدة البيانات داخل `rooms/service.py` واستدعاؤها من `router.py`.

## 10. Edge Cases (الحالات الطرفية)

- إدخال اسم غرفة فارغ أو مسافات فقط -> رفض 400 VALIDATION_ERROR.
- محاولة الانضمام لغرفة غير موجودة بـ UUID وهمي -> 404 ROOM_NOT_FOUND.
- محاولة الانضمام مرتين لنفس الغرفة -> 409 ALREADY_IN_ROOM.
- تمرير معلمات ترقيم سالبة أو تتجاوز الحد الأقصى -> ضبط وتصحيح تلقائي أو رفض 422.
