# واجهات استعراض وإنشاء والانضمام للغرف (Rooms Management UI)

## 1. معلومات المهمة

- **رقم المهمة**: `TASK-03-AHMED`
- **العضو المسؤول**: أحمد العماري
- **الدور**: قائد الفريق + مهندس الواجهات الأمامية
- **الحالة**: جاهزة للتنفيذ بعد TASK-02
- **الأولوية**: عالية (High)

## 2. هدف المهمة

تنفيذ واجهات وتدفقات إدارة الغرف في `frontend/src/pages/RoomsPage.jsx` و `frontend/src/api/rooms.js`:
1. استعراض قائمة الغرف المتاحة مع عدد الأعضاء وتاريخ الإنشاء والترقيم (Pagination).
2. نافذة منبثقة/نموذج إنشاء غرفة جديدة (`POST /rooms`).
3. تدفق الانضمام إلى غرفة (`POST /rooms/{room_id}/join`) ونسخ رابط الدعوة.
4. التوجيه المباشر إلى صفحة الدردشة `/chat/{room_id}` عند الانضمام.

## 3. لماذا هذه المهمة؟

تمكين المستخدمين بعد تسجيل الدخول من استعراض غرف الدردشة الجماعية، أو إنشاء غرف جديدة ودعوة أصدقائهم، أو الانضمام لغرف قائمة والتفاعل معها.

## 8. المتطلبات الوظيفية

1. **خدمة الغرف (`api/rooms.js`)**:
   - `getRooms(limit, offset)`: استدعاء `GET /api/v1/rooms`.
   - `createRoom(name)`: استدعاء `POST /api/v1/rooms`.
   - `joinRoom(roomId)`: استدعاء `POST /api/v1/rooms/{roomId}/join`.
2. **صفحة الغرف (`RoomsPage.jsx`)**:
   - شريط علوي يحتوي على ترحيب بالمستخدم، لغته المفضلة، زر التوجه لـ Dashboard، وزر تسجيل الخروج.
   - زر بارز لإنشاء غرفة جديدة يفتح نافذة (Modal).
   - شبكة عرض بطاقات الغرف (Grid of Room Cards):
     - اسم الغرفة، عدد الأعضاء (`member_count`)، وقت الإنشاء.
     - زر "انضمام ودخول الدردشة" (Join & Chat).
     - زر نسخ رابط الدعوة (Copy Invite Link) مع إشعار نجاح النسخ.
   - إدارة حالات الواجهة:
     - حالة التحميل (Skeleton loaders أو Spinner جذاب).
     - حالة القائمة الفارغة (Empty State) مع رسالة تشجيعية لإنشاء أول غرفة.
     - حالة الخطأ مع زر إعادة المحاولة (Retry).
3. **نافذة إنشاء الغرفة (`CreateRoomModal.jsx`)**:
   - حقل اسم الغرفة (1-100 حرف).
   - زر الإنشاء والتعامل مع حالة الإرسال.
   - عند النجاح: تحديث قائمة الغرف فوراً أو التوجيه لغرفة الدردشة الجديدة.

## 9. المتطلبات غير الوظيفية

- **التصميم والتفاعل**: تصميم عصري للبطاقات وتأثيرات Hover ناعمة تبرز الغرفة عند التمرير بالفأرة.
- **الاستجابة للشاشات**: شبكة عرض متكيفة (1 عمود على الموبايل، 2-3 أعمدة على الشاشات الكبيرة).

## 10. Edge Cases (الحالات الطرفية)

- محاولة الانضمام لغرفة المستخدم عضو فيها مسبقاً (معالجة كود 409 بسلاسة والتوجيه المباشر للمحادثة).
- قائمة الغرف فارغة تماماً -> عرض تصميم Empty State جميل.
- انقطاع الاتصال أثناء جلب الغرف -> إظهار تنبيه وإمكانية إعادة المحاولة.
- إدخال اسم غرفة فارغ في نافذة الإنشاء -> منع الإرسال وتنبيه المستخدم.
