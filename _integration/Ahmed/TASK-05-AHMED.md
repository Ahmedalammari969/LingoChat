# واجهة لوحة التحكم ومؤشرات النظام (Dashboard UI & Stats)

## 1. معلومات المهمة

- **رقم المهمة**: `TASK-05-AHMED`
- **العضو المسؤول**: أحمد العماري
- **الدور**: قائد الفريق + مهندس الواجهات الأمامية
- **الحالة**: جاهزة للتنفيذ بعد TASK-04
- **الأولوية**: متوسطة (Medium)

## 2. هدف المهمة

تنفيذ صفحة لوحة التحكم والإحصائيات في `frontend/src/pages/DashboardPage.jsx` و `frontend/src/api/dashboard.js` لاستعراض مقاييس النظام المسترجعة من `GET /dashboard/stats`:
1. إجمالي عدد المستخدمين (`total_users`).
2. إجمالي عدد الغرف (`total_rooms`).
3. إجمالي عدد الرسائل (`total_messages`).
4. إجمالي عدد الترجمات (`total_translations`).
5. الاتصالات النشطة حالياً (`active_connections`).
6. إضافة رسوم بيانية توضيحية وزر تحديث حي (Refresh).

## 3. لماذا هذه المهمة؟

توفير رؤية شاملة وتفاعلية لإدارة النظام والمستخدمين لمراقبة نشاط المنصة وحجم المحادثات والترجمات المنجزة في الوقت الفعلي.

## 8. المتطلبات الوظيفية

1. **خدمة الإحصائيات (`api/dashboard.js`)**:
   - `getDashboardStats()`: استدعاء `GET /api/v1/dashboard/stats`.
2. **صفحة لوحة التحكم (`DashboardPage.jsx`)**:
   - شريط علوي مع زر العودة للغرف وزر التحديث اليدوي (Refresh).
   - شبكة من البطاقات الإحصائية الملونة (5 بطاقات رئيسية):
     - **المستخدمين**: أيقونة مميزة + الرقم الإجمالي.
     - **الغرف النشطة**: أيقونة الغرف + إجمالي الغرف.
     - **الرسائل المرسلة**: أيقونة الرسائل + إجمالي الرسائل.
     - **الترجمات المنفذة**: أيقونة الذكاء الاصطناعي/الترجمة + إجمالي الترجمات.
     - **الاتصالات الحية**: مؤشر نبض حي (Pulsing Green Badge) + عدد المتصلين الآن.
   - قسم إضافي يعرض نظرة سريعة على صحة النظام وخوادم الترجمة.
   - دعم التحديث التلقائي الدوري كل 10 ثوانٍ (Auto-polling) ليعكس الأرقام الحية.
   - حالات التحميل والأخطاء مع زر إعادة المحاولة.

## 9. المتطلبات غير الوظيفية

- **الجاذبية البصرية**: بطاقات بتأثير Glassmorphism وألوان متناسقة مع التدرجات الحديثة.
- **التجاوب**: ترتيب متناسق للبطاقات عبر كافة أحجام الشاشات.

## 10. Edge Cases (الحالات الطرفية)

- عدم استجابة الخادم أو خطأ 500 -> عرض رسالة خطأ أنيقة مع زر إعادة المحاولة دون تعليق الواجهة.
- استلام قيم أصفار لجميع الحقول -> عرض الأصفار بتنسيق واضح وجميل.
- خروج المستخدم من الصفحة -> إيقاف مؤقت التحديث الدوري (Clear Interval) لمنع تسريب الذاكرة.

## 11. خطوات التنفيذ

- **الخطوة 1**: فحص وتحديث دوال `frontend/src/api/dashboard.js`.
- **الخطوة 2**: تصميم مكون `StatCard.jsx` بتأثيرات بصرية جذابة.
- **الخطوة 3**: بناء صفحة `frontend/src/pages/DashboardPage.jsx` وربطها بالتحديث الدوري.
- **الخطوة 4**: اختبار الصفحة والتحقق من تحديث الأرقام بدقة.
