# فحص الأمان الشامل ومكافحة تسريب الأسرار (10_SECURITY_REVIEW.md)

توضح هذه الوثيقة الخطوات الأمنية الصارمة التي يطبقها القائد لفحص كود العضو قبل الموافقة عليه.

---

## 1. قائمة التدقيق الأمني الإلزامي (Security Audit Checklist)

- [ ] **فحص الأسرار (Secrets Scan)**: البحث عن أي API Keys أو كلمات مرور أو JWT Tokens داخل الكود أو الاختبارات.
- [ ] **فحص التشفير**: التأكد من استخدام `passlib[bcrypt]` بمعامل كلفة 12.
- [ ] **فحص JWT**: التأكد من التحقق من التوقيع وصلاحية الانتهاء واستخراج `sub` كـ UUID.
- [ ] **فحص الصلاحيات وعضوية الغرف**: التأكد من منع المستخدمين غير الأعضاء من الوصول للرسائل أو الاتصال بالـ WebSocket.
- [ ] **فحص حقن البيانات (Injection / XSS)**: التأكد من معالجة المدخلات وعدم تنفيذ استعلامات SQL خام أو حقن HTML غير معالج.

> **قرار فوري**: أي تسريب لمفتاح سري أو ثغرة أمنية يعتبر `FAIL: SECURITY_VIOLATION` حرجاً ويوقف التسليم فوراً.
