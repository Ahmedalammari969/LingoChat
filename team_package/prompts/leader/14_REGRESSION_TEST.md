# فحص واختبار الانحدار (14_REGRESSION_TEST.md)

توضح هذه الوثيقة خطوات فحص الانحدار (Regression Testing) التي يجب إجراؤها بعد كل عملية دمج.

---

## 1. موجهات فحص الانحدار الإلزامية

بعد دمج أي كود جديد في المشروع:
1. **تشغيل حزمة الاختبارات الشاملة المجمعة**:
   ```bash
   pytest backend/tests/ -v
   ```
2. **فحص بناء الواجهات**:
   ```bash
   cd frontend && npm run build
   ```
3. **فحص عدم وجود تآكل في المعمارية (No Architecture Drift)**.
4. **فحص استقرار اختبارات الأعضاء الآخرين**.

> **سياسة الصفر تسامح (Zero Tolerance)**: إذا فشل أي اختبار كان ناجحاً قبل الدمج، يعتبر ذلك انحداراً حرجاً (`REGRESSION_DETECTED`)، ويتم التراجع الفوري عن الدمج وتوجيه العضو لإصلاح التوافقية.
