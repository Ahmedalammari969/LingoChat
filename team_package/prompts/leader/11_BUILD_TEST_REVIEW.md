# فحص البناء وتشغيل الاختبارات (11_BUILD_TEST_REVIEW.md)

توضح هذه الوثيقة إجراءات القائد لتشغيل وفحص الاختبارات والبناء للكود المسلم.

---

## 1. خطوات فحص الاختبارات والبناء

1. **تشغيل اختبارات الوحدة والتكامل للـ Backend**:
   ```bash
   pytest backend/tests/ -v
   ```
   - التأكد من عدم وجود أي Failures أو Errors أو Crashes.
2. **فحص بناء الواجهات (Frontend Build)**:
   ```bash
   cd frontend && npm run build
   ```
   - التأكد من نجاح أمر البناء دون أخطاء.
3. **التحقق من التغطية**: التأكد من تغطية سيناريوهات الـ Edge Cases والأخطاء المعتمدة.

> **قرار فوري**: إذا فشل أي اختبار أو فشل البناء، يتم تعيين الحالة `FAIL: BUILD_OR_TEST_FAILED`.
