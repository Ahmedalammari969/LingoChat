# برومبت الاختبارات المشترك (COMMON_TEST_PROMPT.md)

يوفر هذا الملف الإرشادات والقوالب المشتركة لتشغيل وكتابة وتوثيق اختبارات الوحدة والتكامل لجميع أعضاء فريق **LinguaChat**.

---

## 1. موجهات عامة لكتابة الاختبارات

1. **الاستقلالية والعزل (Isolation)**:
   - يجب أن تكون الاختبارات مستقلة تماماً وتعمل في أي ترتيب دون الاعتماد على حالة اختبار آخر.
   - استخدام Fixtures نظيفة لإنشاء وتفريغ البيانات المؤقتة بعد كل فحص.
2. **تغطية كافة الحالات (Comprehensive Coverage)**:
   - فحص مسارات النجاح الطبيعية (Happy Paths).
   - فحص مسارات الأخطاء والرفض (Error Paths: 400, 401, 403, 404, 409, 422).
   - فحص الحالات الطرفية والمدخلات الفارغة والضخمة (Edge Cases).
3. **أوامر التشغيل المعتمدة**:
   - لتشغيل اختبارات الـ Backend: `pytest backend/tests/ -v`
   - لتشغيل ملف اختبار محدد: `pytest backend/tests/unit/test_auth.py -v`
   - لتشغيل بناء الـ Frontend: `cd frontend && npm run build`

---

## 2. معايير قبول نتائج الاختبار (Acceptance Criteria)

- نسبة النجاح: **100% PASS** (صفر أخطاء Zero Failures / Errors).
- لا يسمح بتجاهل أو تعطيل أي اختبار (`@pytest.mark.skip`) لتمرير الفحص بشكل وهمي.
- زمن استجابة سريع لكافة اختبارات الوحدة.
