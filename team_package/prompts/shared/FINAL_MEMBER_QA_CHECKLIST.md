## قائمة بنود التحقق الذاتي (Self-QA Checklist)

### 1. نطاق المسؤولية والملكية (Scope & Ownership)
- [ ] لم أقم بتعديل أي ملف يقع خارج نطاق مسؤوليتي المحدد في [PROJECT_ROLES.md](file:///d:/FOR/A/kadm/aa/linguachat/team_package/docs/PROJECT_ROLES.md).
- [ ] لم أقم بتنفيذ أي منطق برمجي مخصص لزميل آخر.
- [ ] لم أقم بتعديل أو إضافة أي كود داخل مجلد `team_package/`.

### 2. مطابقة العقود (Contract Compliance)
- [ ] مسارات الـ Endpoints وهياكل الـ JSON مطابقة 100% لـ `API_CONTRACT.md`.
- [ ] رسائل وأكواد الـ WebSocket مطابقة 100% لـ `WEBSOCKET_CONTRACT.md`.
- [ ] نماذج قاعدة البيانات مطابقة 100% لـ `DATABASE_CONTRACT.md`.
- [ ] محركات الترجمة تلتزم بقاعدة `source_used = "identity"` مع منع استخدام `"none"` تماماً وفق `TRANSLATION_CONTRACT.md`.

### 3. الأمان والجودة (Security & Quality)
- [ ] لا توجد أي أسرار، أو كلمات مرور، أو مفاتيح API، أو JWT مخزنة في الكود أو ملفات الاختبار.
- [ ] تم التحقق من سلامة كافة المدخلات ومنع ثغرات الحقن و XSS.
- [ ] لم تتم إضافة أي مكتبات خارجية جديدة دون إذن صريح.

### 4. الاختبارات والنتائج (Tests & Build)
- [ ] جميع اختبارات الوحدة والتكامل الخاصة بي تعمل وتجتاز بنسبة 100% بنجاح.
- [ ] لا توجد أي تحذيرات أو استثناءات غير معالجة في السجلات.
- [ ] تم توثيق النتائج بالكامل في تقرير التسليم الموحد.
