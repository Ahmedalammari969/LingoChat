# 09 - اختبار وتدقيق أحداث الانضمام والمغادرة (09_JOIN_LEAVE_TEST)

## الهدف من الاختبار
التحقق من بث حدث `JOIN` لجميع أعضاء الغرفة عند دخول مستخدم جديد، وبث حدث `LEAVE` عند خروج المستخدم أو انقطاع اتصاله.

## الملفات الخاضعة للاختبار
- `backend/app/websocket/router.py`
- `backend/tests/websocket/test_websocket_events.py`

## المتطلبات المسبقة
- إكمال مرحلة `08_JOIN_LEAVE.md`.

## حالات الاختبار (Test Cases)
1. **فحص بث حدث JOIN**: اتصال مستخدم واستلام المستخدمين الآخرين لحدث الانضمام.
2. **فحص بث حدث LEAVE**: إغلاق العميل لقناته واستلام بقية الأعضاء لحدث المغادرة.
3. **فحص عدم إرسال JOIN لغرف أخرى**: التأكد من عزل الأحداث داخل الغرفة الواحدة.

## أوامر التشغيل
```bash
pytest backend/tests/websocket/test_websocket_events.py -v
```

- نجاح 100% لاختبارات أحداث الانضمام والمغادرة.

## شروط الرسوب (FAIL)
- فشل استلام الأحداث أو عدم تنظيف العميل عند المغادرة.
