# 06 - بناء التحقق الأمني من المصادقة والعضوية (06_WEBSOCKET_AUTH)

## الهدف
بناء وتطوير معالج التحقق الأمني المسبق (Pre-Accept Handshake) في مسار الـ WebSocket `/ws/{room_id}` للتحقق من توكن JWT في الـ Query Params والتحقق من وجود الغرفة وعضوية المستخدم وإغلاق الاتصال بأكواد الإغلاق المعتمدة (4001, 4003, 4004).

## اقرأ أولًا

- `team_package/contracts/SECURITY_CONTRACT.md`
- `backend/app/core/security.py`
- `backend/app/rooms/service.py` (دالة is_user_member_of_room)

## المتطلبات الوظيفية
1. استقبال مسار `@router.websocket("/ws/{room_id}")`.
2. استخراج `token: Optional[str] = Query(None)`.
3. فحص الـ JWT: إذا كان مفقوداً أو منتهي الصلاحية -> إغلاق الاتصال فوراً بكود `4001` (`reason="Unauthorized"`).
4. فحص الغرفة: إذا كانت غير موجودة -> إغلاق بكود `4004` (`reason="Room not found"`).
5. فحص العضوية: استدعاء `is_user_member_of_room`، وإذا لم يكن عضواً -> إغلاق بكود `4003` (`reason="Forbidden"`).
6. عند اجتياز الفحوصات: قبول الاتصال `await websocket.accept()` وتسجيله في `manager`.

## المتطلبات غير الوظيفية
- عدم قبول الاتصال قبل اجتياز الفحوصات الأمنية لتوفير موارد الخادم.

## Edge Cases
- محاولة اتصال دون تمرير باراميتر `token`.
- محاولة اتصال بتوكن مزور أو منتهي.
- اتصال لغرفة غير موجودة بـ UUID عشوائي.

## خطوات التنفيذ
1. كتابة دالة التحقق الأمني المسبق داخل `websocket/router.py`.
2. ربط استدعاء فك التوكن وفحص العضوية.
3. إدارة إغلاق الاتصال بالأكواد المعتمدة.

## التحقق
- فحص استجابة الخادم عند محاولة الاتصال بتوكنات خاطئة أو لغرف غير موجودة.
