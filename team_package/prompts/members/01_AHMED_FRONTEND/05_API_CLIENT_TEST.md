# 05 - اختبار وتدقيق عميل الـ API المركزي (05_API_CLIENT_TEST)

## الهدف من الاختبار
التحقق من صحة عمل عميل الـ API المركزي، والتأكد من حقن ترويسة التوكن، واستخراج الأخطاء بالصيغة القياسية.

## الملفات الخاضعة للاختبار
- `frontend/src/api/client.js`

## المتطلبات المسبقة
- إكمال مرحلة `04_API_CLIENT.md`.

## حالات الاختبار (Test Cases)
1. **فحص الـ Base URL**: التأكد من توجيه الطلبات إلى `/api/v1`.
2. **فحص حقن التوكن**: التحقق من إضافة ترويسة `Authorization: Bearer ...` عند وجود توكن في `localStorage`.
3. **فحص معالجة الأخطاء**: التحقق من استخراج كود الخطأ ورسالته من استجابة `error`.
4. **فحص معالجة 401**: التحقق من إزالة التوكن المنتهي من التخزين المحلي.

## أوامر التشغيل
```bash
cd frontend
npm run build
```

## معايير النجاح (PASS)
- نجاح بناء المشروع.
- صحة كافة دوال التعامل مع الطلبات والاستجابات والأخطاء.

## شروط الرسوب (FAIL)
- تسريب التوكن في السجلات أو فشل استخراج كائنات الأخطاء.

## ما الذي يتم تسجيله في التقرير
- ملخص فحص دوال العميل ونتائج فحص البناء.
