# 10 - بناء واجهة المحادثة التفاعلية الفورية (10_CHAT_UI)

## الهدف
بناء وتطوير واجهة غرفة المحادثة متعددة اللغات في `frontend/src/pages/ChatPage.jsx` لعرض تاريخ الرسائل السابقة المترجمة والرسائل الفورية ومؤشر الكتابة.

## اقرأ أولًا
- `team_package/contracts/API_CONTRACT.md` (القسم 6 استرجاع تاريخ الرسائل)
- `team_package/contracts/WEBSOCKET_CONTRACT.md`
- `team_package/contracts/TRANSLATION_CONTRACT.md`

## الملفات المسموح تعديلها
- `frontend/src/pages/ChatPage.jsx`
- `frontend/src/components/**` (فقاعات الرسائل، مؤشر الكتابة، صندوق الإدخال)

## الملفات الممنوع تعديلها
- `backend/**`
- `team_package/**`

## المتطلبات الوظيفية
1. **استرجاع الرسائل السابقة (`GET /api/v1/rooms/{id}/messages`)**:
   - عرض الرسائل السابقة مترجمة للغة المستخدم مع النص الأصلي.
2. **عرض فقاعة الرسالة (Message Bubble)**:
   - تمييز رسائل المستخدم الحالي عن رسائل الآخرين.
   - إبراز النص المترجم بوضوح مع إمكانية عرض النص الأصلي.
   - عرض شارة مصدر الترجمة (`translation_source`).
3. **أحداث النظام**:
   - عرض أحداث الانضمام `JOIN` والمغادرة `LEAVE`.
   - عرض مؤشر "فلان يكتب الآن..." (`TYPING`).
4. **صندوق الإدخال**:
   - حقل إدخال يدعم Enter للإرسال و Shift+Enter لسطر جديد.
   - إرسال حدث Typing عند الكتابة.

## المتطلبات غير الوظيفية
- رسوم متحركة ناعمة للرسائل.
- التمرير التلقائي لأسفل عند وصول رسالة جديدة.

## Edge Cases
- رسائل طويلة جداً أو متعددة اللغات في نفس المحادثة.
- فشل الترجمة واستلام النص الأصلي كبديل.

## خطوات التنفيذ
1. تصميم مكون `MessageBubble.jsx` ومؤشر `TypingIndicator.jsx`.
2. تصميم ترويسة الغرفة وشريط الإدخال.
3. تجميع صفحة `frontend/src/pages/ChatPage.jsx` وربطها باسترجاع الرسائل السابقة.

## التحقق
- فحص طريقة عرض الفقاعات وشارات الترجمة وتناسق النصوص العربية والإنجليزية.
