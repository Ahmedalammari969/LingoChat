- `frontend/src/api/dashboard.js`

## حالات الاختبار (Test Cases)
1. **فحص عرض المقاييس**: التحقق من عرض الحقول الخمسة بدقة.
2. **فحص زر التحديث**: جلب البيانات عند النقر.
3. **فحص تنظيف المؤقت**: التأكد من استدعاء `clearInterval` عند إلغاء تحميل المكون.
4. **فحص البناء**:

   ```bash
   cd frontend && npm run build
   ```
