# 14 - بناء واجهة لوحة التحكم ومؤشرات النظام (14_DASHBOARD_UI)

## الهدف
بناء وتطوير واجهة لوحة التحكم في `frontend/src/pages/DashboardPage.jsx` مع دوال الاستدعاء في `api/dashboard.js` لاستعراض المقاييس الخمسة من مسار `GET /api/v1/dashboard/stats` مع التحديث الدوري.

## اقرأ أولًا
- `team_package/contracts/API_CONTRACT.md` (القسم 7 /dashboard/stats)
- `frontend/src/api/client.js`

## الملفات المسموح تعديلها
- `frontend/src/pages/DashboardPage.jsx`
- `frontend/src/api/dashboard.js`
- `frontend/src/components/**` (بطاقات الإحصائيات StatCard)

## الملفات الممنوع تعديلها
- `backend/**`
- `team_package/**`

## المتطلبات الوظيفية
1. **استعراض المقاييس الخمسة**:
   - `total_users` (إجمالي المستخدمين).
   - `total_rooms` (إجمالي الغرف).
   - `total_messages` (إجمالي الرسائل).
   - `total_translations` (إجمالي الترجمات).
   - `active_connections` (الاتصالات النشطة حالياً).
2. **التحديث التلقائي**:
   - مؤقت polling كل 10 ثوانٍ لتحديث البيانات الحية.
   - زر التحديث اليدوي (Refresh).
3. **تصميم البطاقات**:
   - بطاقات إحصائية ملونة وجذابة بتأثير Glassmorphism.

## المتطلبات غير الوظيفية
- تنظيف مؤقت التحديث عند مغادرة الصفحة لمنع تسريب الذاكرة.

## Edge Cases
- قيم أصفار في قاعدة بيانات فارغة -> عرض الأصفار بأناقة.
- فشل الاستجابة -> عرض تنبيه الخطأ مع زر إعادة المحاولة.

## خطوات التنفيذ
1. كتابة دالة `getDashboardStats` في `frontend/src/api/dashboard.js`.
2. تصميم مكون البطاقة `StatCard.jsx`.
3. تجميع صفحة `DashboardPage.jsx` وإدارة التحديث الدوري.
