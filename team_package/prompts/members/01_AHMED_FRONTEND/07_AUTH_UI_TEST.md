# 07 - اختبار وتدقيق واجهات المصادقة (07_AUTH_UI_TEST)

## الهدف من الاختبار
التحقق من صحة نماذج المصادقة وتدفق تسجيل الدخول وحفظ واسترجاع التوكن، والتعامل مع الأخطاء.

## الملفات الخاضعة للاختبار
- `frontend/src/pages/LoginPage.jsx`
- `frontend/src/hooks/useAuth.js`
- `frontend/src/api/auth.js`

## المتطلبات المسبقة
- إكمال مرحلة `06_AUTH_UI.md`.

## حالات الاختبار (Test Cases)
1. **فحص التحقق من المدخلات**: رفض أسماء المستخدمين القصيرة أو كلمات المرور الضعيفة.
2. **فحص التبديل بين النماذج**: الانتقال السلس بين شاشة التسجيل وشاشة الدخول.
3. **فحص تخزين التوكن**: التأكد من تخزين التوكن في `localStorage` عند استلام كود 200.
4. **فحص مسح التوكن عند الخروج**: التأكد من حذف التوكن من `localStorage` عند استدعاء `logout()`.
5. **فحص البناء**:
   ```bash
   cd frontend && npm run build
   ```

## أوامر التشغيل
```bash
cd frontend
npm run build
```
