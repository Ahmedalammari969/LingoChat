# 02 - بناء نظام التصميم والتنسيقات الأساسية (02_FRONTEND_FOUNDATION)

## الهدف
بناء وتحديث نظام التنسيقات والتصميم المرئي المتقدم في `frontend/src/index.css` وتجهيز المتغيرات اللونية والتجاوب والتأثيرات الزجاجية.

## اقرأ أولًا
- `team_package/prompts/shared/UI_UX_SYSTEM.md`
- `frontend/src/index.css`

## الملفات المسموح تعديلها
- `frontend/src/index.css`
- `frontend/src/App.css` (إن لزم الأمر)

## الملفات الممنوع تعديلها
- `backend/**`
- `team_package/**`

## المتطلبات الوظيفية
1. تعريف متغيرات CSS (CSS Variables) للألوان الأساسية والتدرجات والخلفيات المظلمة (Dark Slate).
2. فئات مساعدة لكروت الـ Glassmorphism، والأزرار الحديثة، والـ Spinners، وشارات الحالة.
3. دعم التجاوب الكامل للشاشات الصغيرة والمتوسطة والكبيرة.
4. دعم اتجاه النصوص (LTR و RTL) بسلاسة.

## المتطلبات غير الوظيفية
- مظهر عصري واحترافي يمنح انطباعاً بالجودة العالية.
- سرعة تحميل عالية بدون مكتبات ثقيلة.

## Edge Cases
- شاشات الهواتف الضيقة جداً (Mobile Portrait).
- النصوص الطويلة التي قد تسبب تشوه التخطيط.

## خطوات التنفيذ
1. فتح وتعديل `frontend/src/index.css`.
2. إضافة لوحة الألوان المعتمدة من `UI_UX_SYSTEM.md`.
3. كتابة كلاسات البطاقات والأزرار ونوافذ الحوار والتنبيهات.
4. ضبط إعدادات الـ Reset و Box-Sizing والخطوط العامة.

## التحقق
- فحص الصفحة الرئيسية في المتصفح والتأكد من تناسق الألوان وتجاوب التصميم.

## الاختبارات
- تنفيذ المرحلة التالية `03_FRONTEND_FOUNDATION_TEST.md`.

## معايير النجاح
- تطبيق نظام CSS كامل ونظيف ومطابق لمواصفات التصميم.

## شروط التوقف
- التوقف عند حدوث أي أخطاء في الـ CSS Syntax تؤدي لكسر بناء الواجهة.

## ممنوعات المهمة
- ممنوع استخدام مكتبات CSS ضخمة دون إذن القائد.

## التسليم
- الانتقال لاختبار المرحلة عبر `03_FRONTEND_FOUNDATION_TEST.md`.
