# 13 - اختبار وتدقيق عميل الـ WebSocket (13_WEBSOCKET_CLIENT_TEST)

## الهدف من الاختبار
التحقق من صحة اتصال عميل الـ WebSocket، وإرسال نبضات الـ Heartbeat كل 30 ثانية، واستقبال الأحداث، وإعادة الاتصال التلقائي.

## الملفات الخاضعة للاختبار
- `frontend/src/services/websocket.js`
- `frontend/src/hooks/useWebSocket.js`

## المتطلبات المسبقة
- إكمال مرحلة `12_WEBSOCKET_CLIENT_INTEGRATION.md`.

## حالات الاختبار (Test Cases)
1. **فحص عنوان الاتصال**: التأكد من تمرير `?token=` في رابط الاتصال.
2. **فحص مؤقت Heartbeat**: التحقق من انطلاق الرسالة كل 30 ثانية.
3. **فحص معالجة أكواد الإغلاق**: التأكد من التعامل مع 4001 و 4003 و 4004.
4. **فحص البناء**:
   ```bash
   cd frontend && npm run build
   ```

## أوامر التشغيل
```bash
cd frontend
npm run build
```

## معايير النجاح (PASS)
- نجاح بناء المشروع واستقرار كود العميل والخطاف.

## شروط الرسوب (FAIL)
- فشل البناء أو تسريب مؤقتات النبضات.

## ما الذي يتم تسجيله في التقرير
- ملخص فحص عميل الـ WebSocket ونتائج البناء.
