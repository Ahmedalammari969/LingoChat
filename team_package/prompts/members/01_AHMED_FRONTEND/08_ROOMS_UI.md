# 08 - بناء واجهات استعراض وإنشاء والانضمام للغرف (08_ROOMS_UI)

## الهدف
بناء وتطوير واجهات الغرف في `frontend/src/pages/RoomsPage.jsx` مع دوال الاستدعاء في `api/rooms.js` لعرض الغرف، إنشاء غرفة جديدة، والانضمام.

## اقرأ أولًا
- `team_package/contracts/API_CONTRACT.md` (مسارات /rooms و /rooms/{id}/join)
- `frontend/src/api/client.js`

## الملفات المسموح تعديلها
- `frontend/src/pages/RoomsPage.jsx`
- `frontend/src/api/rooms.js`
- `frontend/src/components/**` (بطاقات الغرف ومودال الإنشاء)

## الملفات الممنوع تعديلها
- `backend/**`
- `team_package/**`

## المتطلبات الوظيفية
1. **استعراض قائمة الغرف (`GET /api/v1/rooms`)**:
   - عرض اسم الغرفة، عدد الأعضاء (`member_count`)، وزر الانضمام.
2. **إنشاء غرفة جديدة (`POST /api/v1/rooms`)**:
   - نافذة منبثقة (Modal) لإدخال اسم الغرفة.
   - عند النجاح: تحديث القائمة أو التوجيه لصفحة الدردشة.
3. **الانضمام للغرفة (`POST /api/v1/rooms/{id}/join`)**:
   - الانضمام والتوجيه التلقائي للمحادثة.
4. **نسخ رابط الدعوة**:
   - زر لنسخ رابط الغرفة مع تنبيه بنجاح النسخ.

## المتطلبات غير الوظيفية
- تصميم عصري لبطاقات الغرف (Grid Layout).
- حالات التحميل والتنبيهات الواضحة.

## Edge Cases
- قائمة الغرف فارغة -> عرض شاشة Empty State تشجيعية.
- محاولة الانضمام لغرفة المستخدم منضم لها مسبقاً (409) -> التوجيه المباشر للمحادثة بسلاسة.

## خطوات التنفيذ
1. كتابة دوال `getRooms`, `createRoom`, `joinRoom` في `frontend/src/api/rooms.js`.
2. تصميم مكونات بطاقة الغرفة `RoomCard.jsx` ونافذة الإنشاء.
3. تجميع صفحة `frontend/src/pages/RoomsPage.jsx` وإدارة حالات القائمة.
