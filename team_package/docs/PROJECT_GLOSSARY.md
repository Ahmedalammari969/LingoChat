# قاموس مصطلحات المشروع الموحد (PROJECT_GLOSSARY.md)

يوحد هذا الملف المصطلحات التقنية والوظيفية المستخدمة في مشروع **LinguaChat** لضمان تطابق الفهم بين جميع أعضاء الفريق والوثائق.

---

## 1. مصطلحات المعمارية والنظام (Architecture & System)

- **LinguaChat**: نظام محادثة جماعية متعدد اللغات يعمل في الوقت الفعلي مع ترجمة آلية فورية للرسائل.
- **FastAPI**: إطار عمل الـ Backend بلغة بايثون، يعتمد على البرمجة غير المتزامنة (Asynchronous Python) ومعايير OpenAPI.
- **React SPA**: تطبيق الواجهة الأمامية أحادي الصفحة مبني باستخدام Vite ومكتبة React.
- **PostgreSQL**: قاعدة البيانات العلائقية الأساسية لحفظ المستخدمين والغرف والرسائل والترجمات.
- **SQLAlchemy Async**: أداة الربط الكائني مع قاعدة البيانات (ORM) بالنمط غير المتزامن.
- **Alembic**: نظام إدارة إصدارات وهجرات قاعدة البيانات (Database Migrations).
- **Redis**: مخزن بيانات مفتاح-قيمة سريع في الذاكرة يستخدم اختيارياً كطبقة كاش للترجمات.

---

## 2. مصطلحات الأمان والمصادقة (Security & Auth)

- **JWT (JSON Web Token)**: رمز المصادقة المعتمد الممرر عبر ترويسة `Authorization: Bearer <token>` أو عبر Query Param في الـ WebSocket.
- **Passlib Bcrypt**: خوارزمية تشفير وتجزئة كلمات المرور المعتمدة بمعامل كلفة 12 (`rounds=12`).
- **Access Token**: الرمز المؤقت الممنوح للمستخدم بعد تسجيل الدخول ومدة صلاحيته الافتراضية 60 دقيقة.
- **Token Expiry (exp)**: حقل انتهاء صلاحية التوكن بتوقيت UTC بصيغة Unix Timestamp.
- **Subject (sub)**: حقل المعرف الفريد للمستخدم (`user_id` بصيغة UUID) داخل حمولة JWT.

---

## 3. مصطلحات الويب سوكت والاتصال الفوري (WebSocket & Real-Time)

- **Connection Manager**: فئة إدارة الاتصالات الحية وحفظ قنوات الـ WebSocket المفتوحة لكل غرفة.
- **Message Envelope**: الغلاف الموحد لكافة رسائل الويب سوكت المكون من 4 حقول: `type`, `payload`, `timestamp`, `room_id`.
- **Message Types**: الأنواع الستة المعتمدة حصراً:
  - `JOIN`: انضمام مستخدم للغرفة.
  - `LEAVE`: مغادرة أو انقطاع مستخدم عن الغرفة.
  - `TEXT_MESSAGE`: رسالة نصية واردة أو صادرة مترجمة.
  - `TYPING`: مؤشر بدء أو توقف الكتابة.
  - `HEARTBEAT`: نبضة الحفاظ على الاتصال المرسلة كل 30 ثانية.
  - `ERROR`: إشعار الخطأ المرسل للعميل.
- **Close Codes**: أكواد إغلاق قناة الويب سوكت الرسمية: `4001` (غير مصرح)، `4003` (ممنوع/ليس عضواً)، `4004` (الغرفة غير موجودة)، `1000` (إغلاق طبيعي).
- **Inactivity Timeout**: مهلة انقطاع النشاط (90 ثانية) التي يفصل الخادم الاتصال بعدها إذا لم يتلقَ نبضات أو رسائل.

---

## 4. مصطلحات الترجمة والذكاء الاصطناعي (Translation)

- **LibreTranslate**: محرك ومزود الترجمة الأساسي المعتمد في النظام (Primary Provider).
- **Google Translate Provider**: مزود الترجمة الاحتياطي الاختياري (Fallback Provider).
- **Language Detector**: وحدة الكشف التلقائي عن لغة النص المكتوب باستخدام ISO 639-1.
- **Identity Translation**: آلية إعادة النص الأصلي فوراً مع `source_used = "identity"` و `confidence = 1.0` عند تطابق لغة المصدر مع لغة الهدف (`source_lang == target_lang`).
- **Translation Cache**: طبقة التخزين المؤقت للترجمات المتكررة بمفتاح `translate:{source}:{target}:{sha256(text)}`.
- **Allowed Source Used Values**: القيم الأربعة المعتمدة حصراً لمصدر الترجمة:
  `"libretranslate"`, `"google"`, `"cache"`, `"identity"`. (يمنع استخدام `"none"`).
