# بروتوكول وقواعد استخدام الذكاء الاصطناعي (AI_DEVELOPMENT_RULES.md)

توضح هذه الوثيقة بروتوكول التفاعل الآمن والصحيح مع أدوات الذكاء الاصطناعي (مثل Google Antigravity / Gemini / ChatGPT) أثناء تنفيذ مهام مشروع **LinguaChat**.

---

## 1. الحلقة الإلزامية لاستخدام الذكاء الاصطناعي (The AI Loop)

عند توجيه الذكاء الاصطناعي لتنفيذ أي مهمة، يجب اتباع هذه الخطوات التسع بالترتيب:

```text
1. READ: قراءة ملف المهمة والعقود المرتبطة بالكامل قبل كتابة أي سطر.
2. PLAN: صياغة خطة عمل داخلية دقيقة تلتزم بنطاق الملكية.
3. IMPLEMENT: كتابة الكود حصرياً داخل الملفات المسموح بتعديلها.
4. TEST: كتابة وتشغيل الاختبارات للتأكد من خلو الكود من الأخطاء.
5. REVIEW: إجراء مراجعة ذاتية وسحابية (Cloud Review) للتأكد من مطابقة العقود.
6. FIX: تصحيح أي أخطاء أو ملاحظات تم اكتشافها.
7. TEST: إعادة تشغيل الاختبارات للتأكد من نجاحها 100%.
8. HANDOFF: صياغة تقرير التسليم الموحد في _integration/<Member>/.
9. STOP: التوقف الفوري وعدم البدء بمهمة جديدة دون موافقة القائد.
```

---

## 2. قواعد توجيه الذكاء الاصطناعي (Prompting Guidelines)

1. **استخدام البرومبتات الرسمية فقط**: انسخ نص البرومبت المخصص لمهمتك والموجود في `team_package/prompts/members/<Your_Directory>/`.
2. **منع التخمين والافتراض**: وجه الذكاء الاصطناعي دائماً لفحص الملفات الموجودة فعلياً في المستودع قبل الافتراض.
3. **تثبيت قيود النطاق**: ذكر الذكاء الاصطناعي بالملفات الممنوعة عليه بشكل صريح في كل محادثة.
4. **حظر اختراع مسارات أو حقول**: التأكيد على الالتزام الصارم بأسماء المسارات والأنواع المحددة في `contracts/`.
5. **معاملة `team_package/` كمرجع للقراءة فقط**: التأكيد على عدم كتابة أي كود أو تعديل داخل `team_package/`.

---

## 3. التعامل مع أخطاء الذكاء الاصطناعي الشائعة

| الخطأ الشائع للـ AI | الإجراء التصحيحي الفوري |
| :--- | :--- |
| محاولة إنشاء مشروع جديد بالكامل | رفض الطلب وتوجيهه للتعديل داخل الملفات المحددة في `backend/` أو `frontend/`. |
| استخدام قيمة `source_used = "none"` في الترجمة | تصحيحها فوراً إلى `"identity"` عند تطابق اللغات أو مصدر المزود الحقيقي. |
| تعديل ملفات تخص زميل آخر | التراجع الفوري عن التعديل وإعادة حصر العمل في الملفات المسموحة. |
| اختراع رسائل WebSocket جديدة | الالتزام بالأنواع الستة المعتمدة فقط (`JOIN, LEAVE, TEXT_MESSAGE, TYPING, HEARTBEAT, ERROR`). |
| طباعة التوكنات أو كلمات المرور | إزالة أوامر الطباعة فوراً والالتزام بمعايير الأمان. |
