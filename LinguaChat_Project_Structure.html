تفصيل الطبقات الأساسية للنظام (Architecture Breakdown)
1. بوابة الباكيند ومسار البيانات FastAPI Core
  • محرك خفيف وسريع: مبني على FastAPI مع دعم كامل للـ Async I/O.
  • حماية الجلسات: مصادقة مركزية عبر JWT Bearer وحقن الاعتماديات get_current_user.
  • معالجة موحدة للأخطاء: استجابات قياسية مطابقة لمعيار RFC 7807 Problem Details.
2. محرك الترجمة الذكي وقاعدة Identity AI Translation Engine
  • قاعدة Identity الصارمة: عند source == target تُرجع النتيجة فوراً بـ source_used='identity' و ثقة 1.0 دون استدعاء أي مزود.
  • سلسلة المزودات: كشف اللغة -> الكاش (SHA-256) -> LibreTranslate -> Google Fallback.
  • منع "none": حظر قاطع لاستخدام القيمة "none" في حقل مصدر الترجمة.
3. خادم الـ WebSocket والاتصال الحي Real-Time WebSocket
  • مدير الاتصالات ConnectionManager: غرف محادثة معزولة وتتبع حالة الحضور.
  • إطارات البروتوكول: هياكل صارمة لأحداث join, leave, msg, typing, ping/pong.
  • نبضات القلب (Heartbeat): إدارة مهلة الاتصال وفصل الجلسات الخاملة تلقائياً (90 ثانية).
4. واجهة المستخدم الحديثة (Frontend) React 18 SPA
  • بناء فائق السرعة: مهيأة بالكامل عبر Vite بدون أي تحذيرات بناء.
  • تجربة محادثة حية: مؤشرات كتابة فورية، فقاعات ترجمة تفاعلية، وشارات لمصدر الترجمة.
  • لوحة تحكم إحصائية: رسوم بيانية ومقاييس لاستهلاك الترجمة ونشاط الغرف.
