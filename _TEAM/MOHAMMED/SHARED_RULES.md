# القواعد المشتركة لمحمد الداعس (SHARED_RULES.md)

1. **الالتزام بالعقود**: الالتزام الصارم بـ `_TEAM/00_SHARED/WEBSOCKET_CONTRACT.md`.
2. **الأنواع الستة فقط**: لا تنشئ أي نوع رسالة جديد؛ الأنواع المعتمدة فقط: `JOIN`, `LEAVE`, `TEXT_MESSAGE`, `TYPING`, `HEARTBEAT`, `ERROR`.
3. **أكواد الإغلاق**: استخدام الأكواد الرسمية فقط: `4001` (غير مصرح)، `4003` (ممنوع)، `4004` (الغرفة غير موجودة)، `1000` (طبيعي).
4. **حجم الرسالة**: فحص ورفض أي رسالة تتجاوز 4096 بايت بكود `MESSAGE_TOO_LONG`.
5. **الحدود البرمجية**: لا تعدل ملفات الترجمة أو الموديلز بل استدعِ الواجهات الرسمية فقط.
