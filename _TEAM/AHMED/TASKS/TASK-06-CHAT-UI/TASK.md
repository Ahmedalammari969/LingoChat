## لماذا هذه المهمة مهمة للنظام
تمكين المستخدم من قراءة الرسائل بلغته المفضلة ورؤية النص الأصلي وإرسال الرسائل ومتابعة المتواجدين.

## المتطلبات الوظيفية
- استرجاع الرسائل السابقة GET /rooms/{id}/messages.
- عرض فقاعات الرسائل مع إبراز النص المترجم والنص الأصلي وشارة المصدر.
- عرض أحداث JOIN و LEAVE ومؤشر TYPING.
- صندوق الإدخال ودعم Enter للإرسال.

## المتطلبات غير الوظيفية
- انتقالات ناعمة وتمرير تلقائي لأسفل عند وصول رسالة جديدة.

## Edge Cases / الحالات الحدية
- رسائل طويلة أو لغات متعددة في نفس المحادثة.
- فشل الترجمة وعرض النص الأصلي.
