## المتطلبات الوظيفية
- استعراض قائمة الغرف مع عدد الأعضاء GET /rooms.
- إنشاء غرفة جديدة نافذة منبثقة POST /rooms.
- الانضمام لغرفة POST /rooms/{id}/join والتوجيه للدردشة.
- زر نسخ رابط الدعوة.

## المتطلبات غير الوظيفية
- تصميم شبكي عصري لبطاقات الغرف وحالات تحميل أنيقة.

## Edge Cases / الحالات الحدية
- قائمة الغرف فارغة (Empty State).
- الانضمام لغرفة منضم لها مسبقاً (409) -> التوجيه المباشر.
