## كيف تبدأ وتنفذ مهامك؟

1. توجه إلى مجلد المهام `_TEAM/AHMED/TASKS/`.
2. اختر المهمة الحالية بحسب الترتيب (مثلاً `TASK-01-FRONTEND-ANALYSIS`).
3. اقرأ `TASK.md` لفهم المطلوب والمتطلبات والعقود والملفات المسموحة.
4. افتح `01_IMPLEMENT_IDE.md` وانسخ محتواه إلى AI لتنفيذ المهمة.
5. بعد التنفيذ، افتح `02_TEST_IDE.md` وشغل الاختبارات للتأكد من الحصول على `PASS`.
6. قم بتشغيل مراجعة الذكاء الاصطناعي الخارجية عبر `03_EXTERNAL_AI_REVIEW.md`.
7. عند اجتياز المراجعة بنجاح (`PASS`)، أنشئ تقرير التسليم المعتمد.
