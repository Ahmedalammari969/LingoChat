# قواعد الدمج وضمان الجودة (INTEGRATION_RULES.md)

تحدد هذه الوثيقة معايير دمج الكود ومراجعته وضمان عدم الانحدار في مشروع **LinguaChat**.

---

## 1. شروط الدمج
1. اجتياز اختبارات الوحدة والتكامل بنسبة 100% PASS.
2. اجتياز المراجعة السحابية (Cloud Review) بنتيجة PASS وخلو الكود من أي ملاحظات حرجة.
3. اعتماد التقرير رسمياً من قائد المشروع أحمد العماري.

---

## 2. فحص الانحدار (Regression Check)
بعد كل عملية دمج يتم تشغيل الفحص الكامل لكافة وحدات المشروع لضمان عدم تأثر أي ميزات سابقة:
```bash
pytest backend/tests/ -v
cd frontend && npm run build
```
أي فشل يؤدي للتراجع الفوري عن الدمج وتوجيه العضو لإصلاح الخلل.
