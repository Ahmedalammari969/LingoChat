# دستور وقوانين مشروع LinguaChat (PROJECT_CONSTITUTION.md)

هذا الدستور هو المرجع الإداري والتنفيذي الأعلى لمشروع **LinguaChat**. جميع أعضاء الفريق ملزمون بالامتثال الصارم لبنوده.

---

## 1. القوانين الذهبية الحاكمة

1. **مشروع واحد متكامل**: المشروع نظام موحد غير قابل للتجزئة إلى مشاريع فرعية.
2. **قدسية العقود وتجميدها**: العقود الرسمية مجمدة تماماً. يمنع تعديل أي Endpoint، أو حقل JSON، أو اسم جدول، أو نوع رسالة WebSocket دون موافقة القائد أحمد.
3. **احترام حدود الملكية البرمجية (Strict Ownership)**: يمنع تعديل أو لمس أي ملف يقع خارج نطاق مسؤوليتك الصريحة.
4. **منع الأسرار في الكود**: يمنع منعاً باتاً كتابة أي كلمات مرور أو مفاتيح API أو رموز JWT داخل الكود المصدري أو ملفات الاختبار.
5. **حظر إضافة الحزم العشوائية**: يمنع تثبيت أي مكتبة خارجية جديدة دون تصريح خطي صريح من القائد.
6. **دورة العمل الإلزامية**:
   `READ → PLAN → IMPLEMENT → TEST → REVIEW → FIX → TEST → HANDOFF → STOP`.
7. **التوقف الفوري عند التعارض (Stop on Conflict)**: لا تحل أي تعارض في العقود أو المعمارية من تلقاء نفسك؛ توقف فوراً وأبلغ القائد.
8. **الدمج المشروط بالنجاح الكامل (No Merge Without PASS)**: لا يتم دمج أي كود دون تقرير تسليم رسمي واختبارات ناجحة 100%.
9. **حظر القيمة "none" في الترجمة**: يجب الالتزام بقيم مصدر الترجمة المعتمدة (`libretranslate`, `google`, `cache`, `identity`).
10. **عدم تنفيذ الميزات أثناء التأسيس**: عدم البدء بتنفيذ أي كود قبل اعتماد ملفات ومجلدات المهام التنظيمية.
